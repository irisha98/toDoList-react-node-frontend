# 🗂️ Life Planner — Frontend

**Life Planner** — это веб-приложение для планирования задач, разработанное на React. Пользователь может добавлять, редактировать, удалять задачи, а также просматривать их по датам через встроенный календарь.

## 🚀 Демо
[Открыть приложение] (https://planner-react-backend-frontend.netlify.app)

## 🛠️ Технологии

- **React** — построение компонентов и маршрутов
- **Styled Components** — стилизация интерфейса
- **Axios** — взаимодействие с REST API
- **React Calendar** — календарный компонент
- **JavaScript (ES6+)** — логика приложения

## 🎨 Интерфейс

- Адаптивный дизайн, реализованный через `styled-components`
- Календарь с возможностью выбора даты
- Список задач, отображаемый по выбранной дате
- Кнопки для добавления, редактирования и удаления задач

## 🔗 Бэкенд

Фронтенд взаимодействует с отдельным сервером, реализованным на Node.js + Express.  
Бэкенд-репозиторий: [Life Planner — Backend](https://github.com/irisha98/toDoList-react-node-backend.git)
